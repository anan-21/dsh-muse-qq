# Technology rules

Python 3.12+ and Node.js 24, standard libraries only. Linux/macOS source-run
DSHFish at the checksum-pinned upstream baseline; Windows packages are unsupported.
The optional Muse hook needs Bash, jq and Muse's own runtime.

Code is distributed as scripts and modules, not an application installer.
Run both Python test discovery commands and both Node test directories documented
in CONTRIBUTING.md, plus compilation, Bash syntax and whitespace checks.
CI verifies the same contracts on Linux and macOS. Never alter a running account,
server or credential while preparing this public repository.
