# Feature scope

One owner-private text flow: DSHFish → local pre-model topic router → independent
handoff broker → Muse pickup/reply helper → owner-only OneBot send.

Ordinary topics use DSH. Muse topics export only explicitly authorized context
and memory before generation. Ambiguous continuations stay with Muse. Automatic
return requires ordinary-topic evidence and no remote pending or local unknown
work; explicit mode commands remain available. No refusal-triggered routing.

No tools, reasoning, global memory, configuration or credentials in snapshots.
User-scope memories require both documented sharing opt-ins. No Muse transcript
is silently reinserted into DeepSeek. Unsupported owner-private media is rejected
before rendering or vision. The installer is pinned, backed up and reversible.

Acceptance: all 85 offline contract checks, standalone imports/links, private
metadata review and published CI. Real QQ/Muse deployment is not claimed.
